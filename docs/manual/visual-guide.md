# 界面图解

这一页集中展示需要视觉确认的 Maya 操作。截图基于 Maya 2023；界面文字有变化时，以当前版本按钮功能为准。

## Rig Library 总览

![Rig Library 三栏界面：左侧模块库，中间绑定结构，右侧属性面板](../images/rig-library-ui.png)

| 区域 | 用途 | 操作重点 |
| --- | --- | --- |
| 左侧 Module Library | 选择模块或模板 | 只添加当前角色需要的模块 |
| 中间 Rig Structure | 查看和选择实例 | 镜像、启用、定位当前操作对象 |
| 右侧 Properties | 编辑当前阶段参数 | 结构参数与显示参数分阶段修改 |
| 底部操作区 | 验证并推进阶段 | 前进前先处理 Validate 结果 |

## 截图阅读标记

文档中的界面截图遵循同一套规则：

- 红色框表示必须检查的输入或危险操作。
- 蓝色框表示当前步骤的主要操作。
- 绿色框表示完成状态或验证结果。
- 截图标题必须写明阶段、Maya 版本和工具版本。
- 截图下方必须说明“操作前状态”和“操作后结果”。
